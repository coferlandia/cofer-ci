# Manual completo de instalación limpia

La guía canónica de instalación limpia se mantiene en [`docs/CLEAN_INSTALL.md`](docs/CLEAN_INSTALL.md).

Para actualizar una instalación existente —incluidos estados mixtos 0.2.x/0.3.x— use [`docs/UPGRADE.md`](docs/UPGRADE.md) y no ejecute Docker Compose desde un directorio cuya topología no coincida con los contenedores activos.
